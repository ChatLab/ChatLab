Welcome to ChatLab, an **open-source, local-first tool for analyzing chat records**.

We believe you should be able to understand your own social data. But chat histories do not belong to you alone; they also carry the words and trust of your friends and family. Please read the following terms carefully before using this tool.

## 1. Core Functionality & Independence

- **Analysis Only, No Exporting**: This tool only analyzes chat records that have already been exported; we do not provide decryption, packet capture, or chat record export tools. You must obtain the data yourself and ensure it was acquired lawfully.
- **Independent Third-Party Tool**: This project is an independent open-source project and **is not affiliated with any chat platform, company, or organization**.

## 2. Data Privacy & Security

- **Purely Local Analysis**: By default, chat records are stored and analyzed entirely on your device with **zero uploads**.
- **AI Feature Exception**: When you use AI, relevant chat data is sent to the model provider you configure. Please assess the risks and review that provider's privacy policy.
- **Anonymous Usage Statistics**: To improve the product, the app sends an anonymous identifier, runtime information, and feature usage, but does not collect chat content, contacts, or other chat data. You can disable this feature at any time in Settings.

## 3. Data Authorization & Compliance Responsibilities

Chat histories contain not only your data but also content from other participants. Please follow these principles when using this tool:

- **Lawful Authorization Principle**: You may only process chat records in which you participated and that were lawfully obtained. If your analysis involves another participant's privacy, including **private chat contacts or group members**, ensure that you have obtained informed consent.
- **Lawful Use Responsibility**: You must comply with applicable laws and must not use this software for unlawful or infringing conduct, or use software- or AI-generated content to fabricate or spread false or misleading information.

## 4. Risk Warning

- **Official Channels**: Please download the software only from [chatlab.fun](https://chatlab.fun) or [GitHub Releases](https://github.com/ChatLab/ChatLab/releases). Unofficial versions may contain malicious code that could expose API credentials, chat records, or local data.
- **Accuracy of Results**: Analysis results generated by the software or AI may contain errors or hallucinations. They are for reference only and should not be used as legal evidence or as the basis for formal decisions.
